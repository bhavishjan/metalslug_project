# 2D Arcade Game - Metal Slug
This repo is for my final project of Object Oriented Programming at FAST NUCES Islamabad.

I worked with my project partner and tried to implement different features in this arcade game.

We used OOP concepts like inheritence, polymorphism and how to deal with 40 files at a time.

To run the game, just open the project in Visual Studio (either by cloning the repo or by using GitHub Code option above) and run the main.cpp file. (Having SFML installed is mandatory to run the game).
